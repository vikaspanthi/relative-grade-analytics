Relative Grade Analytics - run instructions
1. Keep index.html, styles.css and app.js in one folder.
2. Open index.html in Microsoft Edge or Google Chrome (internet needed once to load SheetJS, Chart.js, jsPDF from CDN).
3. Upload one or more .xlsx/.xls/.csv files. CAT-I / CAT-II are identified ONLY from the MARK_MODE column (CAT1 / CAT2).
4. Choose mode, weights, filters. Visit "Visual Analytics" before generating the PDF so charts are included.
Student data is processed locally in your browser.
